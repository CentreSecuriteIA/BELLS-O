## Modules

- [Evaluator](evaluator.md) — run a dataset through a supervisor and collect structured results.
- [Supervisors](supervisors.md) — wrappers giving supervision systems a unified interface.
- [Datasets](datasets.md) — dataset loaders, including HuggingFace.
- [Preprocessors](preprocessors.md) — input preprocessing and templating.
- [Result Mappers](result_mappers.md) — map raw supervisor output to normalized results.
- [Common](common.md) — shared types and protocols.
